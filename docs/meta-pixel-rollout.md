## 3. 동의 안내창 (ENABLED=true일 때)

- 안내창 하나(`#analyticsConsentBanner`)에 두 항목을 체크박스로 따로 고른다 — "서비스 이용 분석 (Google Analytics 4) · 선택", "Meta 광고 성과 측정 (Meta 픽셀) · 선택". 둘 다 기본 해제.
- 버튼: **모두 허용하지 않음**(둘 다 거부) · **선택 저장**(체크한 것만 허용) · **모두 허용**. 저장 키는 따로(`ld-analytics-consent-v1`, `ld-meta-pixel-consent-v1`)라 한쪽 결정이 다른 쪽을 바꾸지 않는다. 거부해도 사이트 이용은 같다.
- GA4만 이미 결정한 기존 방문자에게는 Meta 선택을 위해 안내창이 한 번 더 뜬다(체크 상태는 저장값대로).
- 푸터 링크 이름은 "분석·광고 설정"(ENABLED=false일 때는 기존 "분석 설정").
- ENABLED=false면 안내창·푸터·동작 모두 지금 공개 중인 GA4 전용 그대로다.

## 4. 코드가 Meta로 보내는 것

- 동의 전: 스크립트·fbq·noscript 이미지 없음 → 요청 0.
- 동의 후: `PageView`만. 첫 화면 1회 + 해시 이동마다 1회(같은 화면 연속 중복 없음), 동의한 순간 현재 화면 1회. 픽셀 자동 PageView(`disablePushState`)·자동 이벤트(`autoConfig false`) 끔, 고급 매칭 값 없음.
- 주소에 인증 토큰·OAuth 복귀 값이 있는 화면은 보내지 않음.
- 철회: `fbq('consent','revoke')`, `_fbp`/`_fbc` 삭제.
