- 문서 버전: `apparel-2026-10-06.3` (**광고 문구 조사 초안** · 서버 연결 코드는 준비만 · 기본 꺼짐)
- 이 문서는 아직 “사례집”이 아니다. 36개 광고 모두 문구는 확인했고, **이미지 · 슬라이드 광고 18개는 실제 이미지를**, **영상 18개 중 8개는 영상 파일을 디코딩한 표본 프레임(장면 · 자막)을** 확인했다(3-1 · 3-3). 음성은 모든 영상에서 미확인, 영상 10개는 아직 미확인.

- 원자료(광고별 메모 · 제외 사유 · 공식 사이트 대조): `research/2026-10-06-apparel-ads-notes.md`

## 0. 이 사례집을 읽는 방법

- 여기 있는 광고는 **성공 광고가 아니다.** 광고 라이브러리는 일반 상업 광고의 노출 · 지출 · 클릭 · 매출 · ROAS를 공개하지 않는다. 모든 사례의 성과는 **미확인**이다.
- 쇼핑몰의 플랫폼 인기 순위, 광고 집행 기간, 같은 소재의 반복 집행은 성공의 근거가 아니다(인기 순위가 어떤 기준인지도 웹에 공개되지 않음).
- 각 사례는 “어떤 상황에서 시험해 볼 만한 전략 유형인가”로만 쓴다. 문구는 그대로 쓰지 않고, 우리 상품의 **확인된 사실**로 다시 쓴다.
- 관찰 범위(광고별 표시는 3장 ‘확인 범위’ 열):
  - **문구**: 36개 전부(광고 ID · 게재 시작일 · 활성 · 광고주 페이지 · 본문 · 연결 도메인 · 버튼).
  - **이미지**: 이미지 · 슬라이드 광고 18개는 광고 라이브러리에 표시된 이미지 전부(슬라이드는 카드 전부, 16장짜리 #35만 10장)를 직접 봤다. ‘여러 버전’ 광고(#4 · #8 · #11 · #12)는 화면에 표시된 1개 버전만 봤다.
  - **영상**: 8개는 영상 전체를 디코딩해 0~3초 0.5초 간격 · 이후 1.5~2초 간격 프레임을 봤다(장면 · 화면 글자). 프레임 사이의 움직임 · 편집과 **음성은 미확인**. 나머지 10개는 미확인(#1은 썸네일만 — 영상 분석 아님). 4장의 영상 관찰 중 [영상] 표시가 없는 것은 문구 기준이다.

## 4. 전략 유형별 사례

각 유형: 관찰 → 시험할 상황 → 필요한 사용자 자료 → 권하지 않을 조건 · 한계 → 알 수 없는 것.
관찰의 출처를 구분한다: **[문구]** 본문 · 상품명 / **[이미지]** 3-1에서 직접 본 이미지 / **[영상]** 3-3의 표본 프레임(음성 미확인). [영상] 표시가 없는 영상 관찰은 문구 기준이다.

### A. 한 벌 여러 연출
- 관찰: [영상] #9 0~1초 착용 + 반전 문구 → 잠금/풀림 대비, #15 테이블 위 단추 연출 시연(착용은 10.5초). [이미지] #23 같은 데님을 여러 착장 · 장소로, #24 같은 세트를 색 · 상황별로 보여줌. [문구] #9 트렌치를 잠그면 하이넥, 풀면 다른 분위기 · 탈착 견장 · 소매 스트랩(영상). #15 단추를 다 잠금/풀기/한쪽 어깨 내림 3가지. #18 벨트 위치 2가지.
- 훅 · 상품 제시: “한 벌인데 입을 때마다 다른 옷” 류의 첫 문장 → 연출 방법 나열 → 사이즈 · 컬러 · 소재.
- 시험할 상황: 상품에 실제로 바뀌는 구조(탈착 · 투웨이 · 단추 · 벨트)가 있고, 착용 사진 · 영상을 연출별로 찍을 수 있을 때. 클릭률이 비교 광고보다 낮고 소재가 단일 착장 사진뿐일 때 시험 후보.
- 필요한 자료: 연출별 착용 사진 · 영상, 구조 사실(탈착 여부 · 소재 혼용률).
- 권하지 않을 조건: 실제로 연출이 하나뿐인 상품, 연출 사진이 없는 경우(문구만 쓰면 근거 없는 주장). 영상 장면은 확인하지 못했으므로 장면 구성은 사례에서 판단하지 않음.
- 알 수 없음: 성과, 연출 수와 반응의 관계.

## 5. LaunchROAS 개선안으로 쓰는 방법

1. 사례는 분석 결과(판정 · 원인 가설)가 정해진 **뒤에** 고른다. 사례 때문에 판정을 바꾸지 않는다.
2. 원인 가설과 맞는 유형만 1~2개 고른다. 예: 클릭률은 비슷한데 장바구니 → 결제가 낮다 → E(혜택 고지) 후보, 단 할인 정보가 사용자 입력에 있을 때만.
3. 변경안 문구는 우리 상품의 확인된 사실(상품명 · 소재 · 사이즈 · 사용자 입력 강점)로 새로 쓴다. 사례 문구를 옮기지 않는다.
4. 필요한 자료가 없으면 “먼저 준비할 자료”로 묻고 변경안은 임시 예시로 표시한다.
5. 권하지 않을 조건에 해당하면 그 유형은 제안하지 않는다.
