# 의류 광고 전략 사례집 (업종별 사례집 1호)

- 문서 버전: `apparel-2026-10-06.1` (초안 · 서버 미적용)
- 공통 판단 기준은 `ad-review-policy.md`. 이 문서는 의류 쇼핑몰이 **시험해 볼 전략 후보**를 실제 광고 관찰로 정리한 자료다.
- 원자료(광고별 메모 · 제외 사유 · 공식 사이트 대조): `research/2026-10-06-apparel-ads-notes.md`

## 0. 이 사례집을 읽는 방법

- 여기 있는 광고는 **성공 광고가 아니다.** 광고 라이브러리는 일반 상업 광고의 노출 · 지출 · 클릭 · 매출 · ROAS를 공개하지 않는다. 모든 사례의 성과는 **미확인**이다.
- 쇼핑몰의 플랫폼 인기 순위, 광고 집행 기간, 같은 소재의 반복 집행은 성공의 근거가 아니다(인기 순위가 어떤 기준인지도 웹에 공개되지 않음).
- 각 사례는 “어떤 상황에서 시험해 볼 만한 전략 유형인가”로만 쓴다. 문구는 그대로 쓰지 않고, 우리 상품의 **확인된 사실**로 다시 쓴다.
- 관찰 범위: 광고 라이브러리 화면의 **텍스트**(광고 ID · 게재 시작일 · 활성 · 광고주 페이지 · 본문 · 연결 도메인 · 버튼 · 영상 여부). **이미지 · 영상 화면은 직접 보지 않았다.** 첫 장면 · 착용 장면 · 자막은 확인하지 못했으므로 문구로 드러난 것만 적는다.

## 4. 전략 유형별 사례

각 유형: 관찰 → 시험할 상황 → 필요한 사용자 자료 → 권하지 않을 조건 · 한계 → 알 수 없는 것.

### A. 한 벌 여러 연출
- 관찰: #9 트렌치를 잠그면 하이넥, 풀면 다른 분위기 · 탈착 견장 · 소매 스트랩(영상). #15 단추를 다 잠금/풀기/한쪽 어깨 내림 3가지. #18 벨트 위치 2가지.
- 훅 · 상품 제시: “한 벌인데 입을 때마다 다른 옷” 류의 첫 문장 → 연출 방법 나열 → 사이즈 · 컬러 · 소재.
- 시험할 상황: 상품에 실제로 바뀌는 구조(탈착 · 투웨이 · 단추 · 벨트)가 있고, 착용 사진 · 영상을 연출별로 찍을 수 있을 때. 클릭률이 비교 광고보다 낮고 소재가 단일 착장 사진뿐일 때 시험 후보.
- 필요한 자료: 연출별 착용 사진 · 영상, 구조 사실(탈착 여부 · 소재 혼용률).
- 권하지 않을 조건: 실제로 연출이 하나뿐인 상품, 연출 사진이 없는 경우(문구만 쓰면 근거 없는 주장). 영상 장면은 확인하지 못했으므로 장면 구성은 사례에서 판단하지 않음.
- 알 수 없음: 성과, 연출 수와 반응의 관계.

### B. 문제 제기 · 걱정 해소
- 관찰: #13 “재킷은 정했는데 바지가 안 따라주는 날” → 워싱 · 통 · 밑단 스냅. #31 “낮엔 더워서 벗고 밤엔 추울 때” 일교차. #20 “브이넥이 부담스러우셨던” → 라운드넥. #23 “논페이드 생지 원단으로 이염 부담 없이”.
- 시험할 상황: 고객 문의 · 후기에서 실제로 반복되는 걱정(이염 · 노출 · 일교차 · 코디)이 확인될 때.
- 필요한 자료: 실제 문의 · 후기 요약, 걱정을 해소하는 상품 사실(원단 · 넥라인 · 기능).
- 권하지 않을 조건: 고객이 그 걱정을 한다는 근거가 없을 때(지어낸 걱정은 공감을 얻지 못하고 사실 오인 위험). “이염 없음” 같은 품질 주장은 사실 확인 없이 쓰지 않음.
- 알 수 없음: 성과.

### C. 제작 · 핏 근거
- 관찰: #19 “63819번 수정한 … 어깨선 1mm” 제작 과정 훅(수치 진위 미확인). #16 “입어본 잘록 가디건 중 1등” 1인칭 비교. #17 “홀리만의 시그니처 팬츠 핏”.
- 시험할 상황: 자체 제작(MADE) 상품이고 패턴 · 수정 과정을 사실로 설명할 수 있을 때.
- 필요한 자료: 실제 제작 과정 사실(수정 횟수 · 부위 · 원단), 핏을 보여주는 착용 자료.
- 권하지 않을 조건: 사입 상품, 수치를 확인할 수 없을 때(과장 수치 · “1등” 같은 비교 표현은 근거가 없으면 쓰지 않음 — 표시광고 관련 위험).
- 알 수 없음: 성과, 수치 표현의 효과.

### D. 판매량 · 사회적 증거
- 관찰: #4 상품명 “[1만장판매]”. #33 “1만 장 돌파 … MADE 가디건” + 55~120 사이즈. #11 “모델도 개인소장함”.
- 시험할 상황: 판매량 · 재구매 · 리뷰 수를 실제 데이터로 말할 수 있을 때. 신규 방문 고객이 많은 광고 세트.
- 필요한 자료: 판매량 근거(기간 · 기준), 리뷰 수 · 평점(출처).
- 권하지 않을 조건: 근거 숫자가 없을 때 — LaunchROAS는 Cafe24 주문에서 확인한 범위 밖의 숫자를 만들지 않는다.

## 5. LaunchROAS 개선안으로 쓰는 방법

1. 사례는 분석 결과(판정 · 원인 가설)가 정해진 **뒤에** 고른다. 사례 때문에 판정을 바꾸지 않는다.
2. 원인 가설과 맞는 유형만 1~2개 고른다. 예: 클릭률은 비슷한데 장바구니 → 결제가 낮다 → E(혜택 고지) 후보, 단 할인 정보가 사용자 입력에 있을 때만.
3. 변경안 문구는 우리 상품의 확인된 사실(상품명 · 소재 · 사이즈 · 사용자 입력 강점)로 새로 쓴다. 사례 문구를 옮기지 않는다.
4. 필요한 자료가 없으면 “먼저 준비할 자료”로 묻고 변경안은 임시 예시로 표시한다.
5. 권하지 않을 조건에 해당하면 그 유형은 제안하지 않는다.
